Rclone Project Backup

A personal Linux backup utility that uses locally installed rclone and the Google Drive API to back up and restore the owner's files.

The application lists and manages files in the owner's Google Drive solely for backup and restoration. Depending on the backup operation, this includes uploading backups, downloading files for restoration, and updating or deleting backup files.

Backup operations run locally on the owner's computer. Backup files are stored in the owner's Google Drive account. This website provides application information; it does not run backups or request Google account access.
